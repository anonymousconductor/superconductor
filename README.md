# SuperConductor

Demo site for the SuperConductor paper: https://anonymousconductor.github.io/superconductor/

Static files only, served by GitHub Pages from the repository root (`.nojekyll` disables
Jekyll).

Preview locally with `make` (serves http://localhost:8138).

- `index.html`, `style.css`: the page.
- `js/table.js`: collaborative-mode readouts, synchronized with the video.
- `js/conducting-tempo.js`, `js/conducting-tempo-data.js`: conductor-mode plots and the
  tempo estimator snapshots they replay.
- `assets/`: videos, figures, the paper PDF, and icons.
